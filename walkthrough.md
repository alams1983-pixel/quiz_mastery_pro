# Walkthrough - Quiz Mastery Pro

The **Quiz Mastery Pro** platform has been updated with a unique, distinct **Royal Emerald Teal & Amethyst Violet Accent** color palette for both Light and Dark modes.

---

## 🎨 New Distinct Theme Palette

- **Primary Brand Color**: Royal Emerald Teal (`#0d9488` / `#0f766e` in Light Mode, `#2dd4bf` / `#14b8a6` in Dark Mode).
- **Accent Highlight**: Amethyst Violet (`#7c3aed` / `#a78bfa` for active badges, subscript `Pro` branding, and tags).
- **Backgrounds**: Soft Icy Mint (`#f0fdfa`) for Light Mode and Deep Midnight Onyx (`#061117`) for Dark Mode.
- **Borders & Controls**: High contrast Slate borders (`#cbd5e1` / `#243c4a`) for clean component boundaries.

---

## 🚀 How to Run the App

1. **Start Backend Server**:
   ```bash
   npm run server
   ```
2. **Start Frontend Client**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in browser.
